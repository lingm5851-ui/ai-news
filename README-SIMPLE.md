# AI News Aggregator

100+ data sources, real-time AI news.

## Features

- Real-time news aggregation from 13+ platforms
- 70+ RSS feeds
- 52+ WeChat public accounts
- Bilingual (Chinese/English)
- Dark mode support
- Search and favorites

## Deploy

```bash
# Install dependencies
pnpm install
cd web && pnpm install

# Fetch data
pnpm run fetch

# Start dev server
cd web && pnpm run dev
```
